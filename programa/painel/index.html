Avatares

  

  

 
Pastas para separar os vídeos de cada avatar. Crie uma pasta com o nome do avatar e clique nela para ver e editar só os vídeos dele. Vídeo adicionado com a pasta aberta já entra nela, e os prontos saem separados em _Prontos\Nome do avatar. Para organizar vídeos que já estão no programa, abra Todos os vídeos, marque os vídeos e use Mover para… (ou o campo Pasta do avatar no cartão).
